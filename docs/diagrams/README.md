# Diagrams

Diagram sources, kept as text so they are reviewable in a pull request.

- **Format:** Mermaid, embedded in Markdown files (`*.md`).
- **Naming:** `c4-context.md`, `c4-container.md`, `sequence-<flow>.md`,
  `er-<area>.md`.
- **Binary exports** (PNG, SVG) are generated artefacts. Do not commit them
  unless an external stakeholder needs them; if you do, regenerate them in the
  same pull request as the source.

The system-level C4 context and container diagrams, the authentication flows
and the deployment topology are already in the root `ARCHITECTURE.md`.
